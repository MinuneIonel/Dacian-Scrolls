# Art style

Pixel art, generated by `python3 tools/art/build.py` from `tools/art/specs/*.json`. Same input, same bytes.
Never hand-edit a PNG: change a generator or a spec and rebuild. `python3 tools/art/test_art.py` must pass.

## Palette (locked, 32 colours, `tools/art/palette.py`)

| Group | Names |
|---|---|
| Outline | `outline` (warm black) |
| Earth, wood, bronze | `brown0..3`, `ochre`, `straw` |
| Stone, steel | `grey0..4` |
| Forest | `green0..4` |
| Skin | `skin0..2` |
| Cloth | `red0..1`, `blue0..2` |
| Lobizi silk | `silk0`, `white` |
| **Lobizi tech only** | `teal`, `cyan`, `magenta`, `acid` (never on Dacian things; tested) |
| Gore | `blood` |

Pixels are palette colours or fully transparent; no partial alpha. Shadows in compositions use
`kit.darken` (one palette step darker), not alpha.

## Sizes and anchors

- Ground tiles: 64x32 diamond (31 filled rows, they tile exactly). `cell_to_world(c)` is the diamond centre: draw at offset (-32, -16).
- Tall tiles (walls): 64 x (32 + height); the diamond is the bottom 32 rows: offset (-32, -(16 + height)). `tile_wall` height is 48.
- Humans: 32x48 frames, feet at `anchor` [16, 44] = the cell centre.
- Giants: 2x2 footprint, 128x192 frames, waist down only; `anchor` [64, 160] = footprint centre.
- `ui_panel`: 48x48, 9-slice with 12 px margins on every side.
- Sheets: one row per animation: `idle` 2, `walk` 4, `attack` 3, `hit` 1, `death` 3, then the same
  for north-east as `idle_ne` ... `death_ne`. Drawn facing SE and NE; the game flips for SW and NW.

## Light and lines

- Light from the top-left. Shapes use 2- or 3-tone ramps (`kit.shade`), lit on the upper-left edge,
  shadow on the lower-right. Large soft surfaces (silk) may use 4x4 ordered dithering; small sprites don't.
- Sprites: 1 px `outline` around the silhouette, and a dark line where a front part overlaps another.
- Ground tiles have no outline (they must join). Walls: lit left face, darker right face, light rim on top.

## Adding a sprite

1. Write a generator (for a humanoid: a gear dict in `gen_chars.GEAR` reusing the rig and poses).
2. Register it in `build.GENERATORS` and add an entry to `tools/art/specs/*.json` (id, gen, size, anchor, out).
3. `python3 tools/art/build.py && python3 tools/art/test_art.py`, then look at the PNG at 3x.
