# WP-16 handoff: UI kit, main menu, settings
- Font: `python3 tools/font/build_font.py` writes the 5x7 bitmap font `assets/fonts/dacian.{png,fnt}` (11 px line, ASCII + ă â î ș ț, uppercase forms, cedilla ş ţ, é ü ö ä … – — ‘ ’ “ ”) and a 2x `dacian_title`.
- `UiKit` (src/ui/kit/ui_kit.gd): `theme()` (set it on your view root), `panel() button(key) label(key) bar(color) choice_list(keys)` (ChoiceList, signal `chosen(index)`, `focus_first()`), `toast_layer()` (ToastLayer: shows Bus.toast and `toast` events for 2.5 s, max 4 stacked).
- Palette consts on UiKit (UMBER, WOOD, BRONZE, PARCHMENT, ..., CYAN only for alien things). Label variations: `TitleLabel`, `DimLabel`, `AlienLabel`.
- Buttons and labels show tr(key) with auto-translate off; the key is in meta `text_key`.
- The panel uses `Assets.tex(&"ui_panel")` as a 9-slice (6 px margins) once the manifest has it; otherwise a flat umber box with a bronze edge.
- Menu: New Game (Knight or Necromancer, seed: number used as-is, text hashed, blank random), Continue, Settings, Quit. `Router.args {"screen": "new"|"settings"}` opens a sub-screen. Settings save when you leave the screen.
- Router: `switch_scenes` (tests set false), `save_fn` (autosave hook, default Game.save), `resume_args()` for Continue. Autosave only with a non-empty party.
- Settings: `apply()` sets fullscreen and the volumes of the "Music" and "SFX" audio buses if they exist (WP-15: please name the buses that). `gore_key()` gives the string key. Corrupt or wrong-type files fall back to defaults without logging errors.
- Gaps: Begin and Continue call Game.new_game/load_slot (WP-10), which tests do not touch. In exports the font loads through the imported .fnt resource (raw file as a fallback).
- The toast layer listens to both Bus.toast and `toast` events, so do not send the same message both ways.
- Gotcha: a `-s` SceneTree script that names UiKit at parse time hangs (the autoloads are not ready yet). Load scenes at runtime instead.
