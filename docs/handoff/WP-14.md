# WP-14 handoff: art pipeline and style spike

- `python3 tools/art/build.py` regenerates assets/{tiles,sprites,ui}, assets/manifest.json ("audio" kept as found) and docs/art-spike.png.
- `python3 tools/art/test_art.py`: determinism (two builds + committed files match), palette-only, manifest paths, sheet/frame counts, no Lobizi colours on Dacian assets, diamond tiling.
- `tests/unit/test_art_assets.gd`: Assets.tex/frames load the real files.
- Kit: `palette.py` (32 locked colours), `kit.py` (diamond, prism, lattice wrap, shade, dither, outline, pack, mirror, darken), `rig.py` (shape rig), `gen_*.py`, `spike.py`.
- Spike assets: tile_grass, tile_road, tile_forest_floor, tile_stone, tile_wall (64x80), knight, grazi_thrall, giant_legs (all anims, SE+NE), ui_panel.
- Frames entries carry an extra `anchor` (and `footprint` for giants); Assets ignores unknown keys. Anchors: docs/art-style.md.
- Tile drawing convention (proposal for views): cell_to_world = diamond centre; tile offset (-32,-16), tall tile (-32,-16-height).
- Gaps: death "lying" frames are rough; giant silk is simple; no gore/icons/portraits (WP-25). Waiting for Cojo's approval of docs/art-spike.png.
- Godot import creates docs/art-spike.png.import (not committed); a `docs/.gdignore` (not mine) would stop that.
