# WP-33 Builds: handoff

- `export_presets.cfg`: Windows Desktop, macOS (universal, ad-hoc signed, not notarised), Linux, Web (single-threaded, no GDExtension: works on GitHub Pages without COOP/COEP). Include filter `*.json, *.csv`; excludes `tests/ tools/ docs/ data/schemas/ build/`. Outputs go to gitignored `build/`.
- `tools/get_templates.sh [linux windows macos web]`: fetches the 4.5.1-stable `.tpz`, checks SHA512, installs into `~/.local/share/godot/export_templates/4.5.1.stable` (only the named platforms if given).
- Local export: `tools/godot.sh --headless --export-release "Linux" build/linux/DacianScrolls.x86_64` (or "Web" `build/web/index.html`). Do the two prep lines from release.yml "Prepare export" first, and `touch build/.gdignore`.
- `.github/workflows/release.yml`: tag `slice-*` (or workflow_dispatch) builds all four, verifies the pack has `data/strings/en.csv` + `data/world.json` and no `tests/`, runs the Linux build headless, attaches `DacianScrolls-{windows,macos,linux}.zip` + how-to-play.md to a prerelease and deploys `build/web` to Pages. Actions pinned by SHA.
- `docs/how-to-play.md`: controls taken from the mode scripts, feedback via the project thread or GitHub issues.
- Verified: Linux export runs headless and under Xvfb/GL with no errors; Web loads in Chromium (not cross-origin isolated) to the menu, New Game reaches Sarmizegetusa with strings, data and art. Sizes: Linux 73 MB (zip 32), Windows 98 MB (zip 39), macOS zip 68 MB, Web 43 MB (wasm 38, pck 5.8).
- Owner setup: Settings > Pages > Source "GitHub Actions"; Settings > Environments > github-pages: allow tags `slice-*` (the default rule only allows the default branch, so a tag deploy is rejected).
