# WP-21 handoff: combat view
- `Router.go(&"combat", {encounter_id, return_mode?, return_args?})`. Builds `Battle` (inventory = copy of `Game.state.inventory`), MapBuilder arena, UnitViews (UnitSprite + side ring + HP bar + status tags) in `Sorted`, Camera2D (shows all units at each turn start, else follows the active unit; arrows/WASD/middle-drag pan).
- Files: `combat.gd` (turn loop, input, result), `event_player.gd` (animates every CONTRACTS section 6 combat event in order), `combat_hud.gd`, `unit_view.gd`, `overlay.gd` (move/target/area/hover/hazard cells, specimen-tank blocks), `combat_text.gd` (`trf`: tr + format that never errors).
- Input: click a cell to move, click an enemy to basic-attack, keys 1-8 / buttons pick an ability (self-area ones preview, press again to fire), Space ends the turn, Esc/right-click cancels, Tab/F toggles 4x. Hover shows HP, statuses and `battle.hit_chance`. Magic greyed with `zalmoxis_cant_hear_you` when `magic_disabled`.
- Injectable: `ai_chooser` (default `Ai.choose`), `party_chooser` (drives party turns too), `battle` (any object with Battle's methods), `audio`, `set_instant(true)`, `set_fast(on)`. Signals: `finished(result)`; on `player`: `unit_damaged(uid, amount, crit, view)` and `unit_died(uid, gib, corpse, view)` are the **gore hooks for WP-32**.
- End: `take_item` for `result.items_used`, then `Encounters.apply_battle_result`, `Bus.emit_events`, plus `fled_battle{}` on flee. Result banner (title, reason, loot) for 4 s or until a click, then `Router.go(return_mode or worldmap, return_args)`. Defeat only returns; `defeat{}` and the wake-up are WP-30's job.
- Music: the map's `music`, else `saucer` if magic is off, else `sarmizegetusa`; combat layer on, off at the end; defeat stinger.
- Shots: `--args='{"encounter_id":"wolves","debug_party":true}'` (knight + Vezina via Game.new_game). `debug_select` (button index) and `debug_hover` ([x,y]) are for screenshots.
- Tests: `tests/integration/test_combat_view.gd` (8): stub battle playback (instant and 4x), clicks go through legal actions, magic greyed, result applied and Router return, self-area ability preview, real fx_wolves and fx_saucer battles to the end.
- Gaps: there are no icons or portraits yet, so buttons and chips are text only. Sprites missing from the manifest borrow knight/grazi_thrall/giant_legs, tinted per def; this stops by itself once WP-25 adds the art. Items show as extra buttons only when legal. No undo for moves.
- Contract request: `Encounters.apply_battle_result` should apply `result.items_used` itself. The view does that now with `Rules.run(take_item)`; move it into core and drop it from `combat.gd._finish`.
- Note for WP-20: until `Ai.choose` is implemented, each enemy turn pushes an error and ends.
