# WP-22 handoff: location mode, dialogue box

- `src/modes/location/location.gd` (root Node2D): `Router.go(&"location", {location_id, cell?})`; location_id is a world location (map + entry_cell from world.json) or a map id; spawn = cell, else entry_cell, else spawn_ally. Writes `Game.state.location_id/location_cell` on every step.
- Party: leader + companions in a conga line (UnitSprite; sprite = npc def sprite for recruits, else class sprite). Click-to-walk (Pathfinder on the MapBuilder grid, NPCs and containers block), WASD/arrows step (W = grid north-east), E interacts with an adjacent NPC/container, camera follows smoothly, hovered cell/interactable highlighted with a name label.
- Entities: npc (visible while its `if` holds; dialogue = entity `dialogue` or npc def `dialogue`), container (flag `opened_<map>_<id>` when once; failed `if` toasts `loc_locked`), trigger (fires on step; flag `triggered_<map>_<id>` when once), exit (worldmap or location), prop. Flags are set through `Rules.run` so they emit `flag_set`.
- Events: all lists go to `Bus.emit_events`; `battle_requested` -> `Router.go(&"combat", {encounter_id, return_mode: &"location", return_args: {location_id, cell}})` (after the dialogue closes), `shop_requested` -> `ShopScreen.show_over(self, id)`.
- HUD: map name, Party (`PartyScreen.show_over`), Scroll (`Router.go(&"scroll")`), hint line. Esc: closes dialogue / an overlay (emits its `closed`) / toggles the pause menu (Resume, Scroll, Quit to Menu). Dungeons get a slight CanvasModulate.
- Music: `Audio.play_music(map.music or sarmizegetusa)`, explore layer on, combat/lobizi off.
- `DialogueBox` (`src/ui/dialogue_box.gd`): `begin(dialogue_id, state, rng, defs, portrait = &"") -> events`, `choose(index)`, `choose_number(n)`, `reveal_all()`, `close()`; signals `events(evts)` (also broadcast on Bus), `closed`. Typewriter 60 chars/s; click/space finish; number keys choose; a node without choices shows (Continue).
- Testing hooks: `walk_to(cell) -> bool`, `finish_walk()`, `step_time`, `talk(id)`, `open_container(id)`, `interact_adjacent()`. Debug args: `debug_party`, `debug_talk:"<npc entity>"`, `debug_pause`.
- Tests: `test_location.gd` (fixtures), `test_location_maps.gd` (real maps: entity reachability, build per location, every town dialogue opens), `test_dialogue_box.gd`.
- Gaps: NPC, prop and portrait art is missing (magenta placeholders / fallback blocks until WP-25). Toasts rely on the Hud autoload (WP-24). No contract change requests.
