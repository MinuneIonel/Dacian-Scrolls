# WP-11 handoff: rules, dialogue, quests, narrator

- `Rules.check(conds, state, defs)` / `Rules.run(effects, state, rng, defs)`: every form of CONTRACTS 7. Malformed, unknown or bad-op forms push exactly one error and are false/skipped.
- Extra public helpers: `Rules.roll_chance(dc, best)`, `best_stat(state, stat)`, `compare(a, op, b)`, `grant_xp(state, n, defs)` (shared XP, use it for encounter XP), `recruit(state, npc_id, defs)`, `reveal_around(state, cell, r, defs)`, `location(id, defs)`, `to_cell(v)`.
- Event details: `gold_changed`/`food_changed`/`item_changed` carry the delta actually applied (clamped). A quest stage not above the current one, a page already found, a known location re-discovered, or recruiting someone already in the party emit nothing. `revealed` is omitted when no new cell.
- `["roll"]` draws exactly one `rng.roll(20)`.
- `DialogueRunner`: call `start()` once, show `current()`, pass a choice's `index` (its position in the node's full list) to `choose()`. Hidden or out-of-range index: `[]`, no change. Missing goto ends with one error; unknown dialogue is done at once.
- `QuestLog.entries`: started quests, active then done, by id; `desc_key` from the highest stage reached.
- `Narrator.lines_for`: at most one line, from the first event with a usable entry. A `narrator{line_key}` event counts and returns its own key, so a HUD can call only `lines_for`. Once-lines in `flags["fanfi_once:<key>"]`.
- Fixtures: `dialogue/fxs_gate.json`, `strings/story.csv` (+ generated import files).
- Tests: `test_rules.gd`, `test_dialogue.gd`, `test_narrator.gd`. No contract change requests.
