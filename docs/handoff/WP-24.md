# WP-24 handoff: scroll, party, shop, Hud, ending card
- **Scroll** (`ScrollMode`, mode `scroll`): parchment (`tools/art/parchment/gen_parchment.py` -> `assets/screens/parchment.png`), 12 slots in page `order` (torn gaps for missing), reader with Fanfi margin notes (`scroll_fanfi_<page_id>`), quest log, Save/Load (slots 1..3, overwrite asks once). Args `{tab?, page?, return_mode?, return_args?}`. `ScrollMode.slot_info(slot)` -> `{state: empty|ok|damaged|too_new, day, pages, level}` via SaveCodec (never errors).
- Back/Load: `return_mode`/`return_args` if given, else `Game.state.mode`; Router.go already set that to `scroll`, so it falls back to location (if `location_id` set) else worldmap. **WP-30: pass `return_mode`/`return_args` when opening the scroll from the world map**, since a stale `location_id` would send Back to the town. Manual saves store the return mode, not `scroll`.
- **PartyScreen**: `select_member(i)`, `toggle_ability(id)` (5th refused, toast `party_abilities_full`), `equip(item)`/`unequip(slot)` (gear leaves the pack; take/give via Rules), `use_item(item)` (use_effects then take 1, broadcast). Items with only `use_ability` show a disabled Use. Gear mods are only displayed (battle math is WP-12's).
- **ShopScreen**: `buy`/`sell`/`remaining`, sold counts in `flags["shop_<id>_<item>"]`, sell = floor(price/2), quest/0-price items unsellable. Toasts `not_enough_gold`, `shop_sold_out`, `shop_wont_buy`.
- **Hud**: `Hud.caption` (`NarratorCaption`: `queue_line`, `skip`, `clear`, 4 s + 0.035 s/char, click skips), `Hud.toasts` (layer 91), `Hud.show_ending()`. No party: only `narrator` events speak. Hud hides its toasts while another ToastLayer exists (the menu adds its own), so modes should not add a toast layer.
- **EndingCard**: opens on `page_found` with 12+ pages. `EndingCard.recap_lines(state, defs)`. Abductions read `flags["times_abducted"]` (int) or count `abducted_*` flags: **WP-30 please set `times_abducted`**.
- `PartyScreen.fmt(key, args)` formats safely (a missing key never raises a format error); `PartyScreen.ink_theme()` is the theme for text on the parchment `ui_panel`.
- Screenshots: `tools/shots.sh res://src/modes/scroll/screens_debug.tscn out.png 20 640x360 --args='{"show":"party"}'` (show: scroll|party|shop|caption|ending; also debug_pages, tab, page, debug_saves, toast).
- Tests: `tests/integration/test_screens.gd` (17), `test_hud.gd` (8). They also load `view_screens.csv` over the fixtures.
- WP-16 note: `ui_panel` has a parchment centre but the theme's Label colour is parchment, so toasts (and any UiKit.panel text) read light-on-light. Suggest dark ink Label colours inside panels.
